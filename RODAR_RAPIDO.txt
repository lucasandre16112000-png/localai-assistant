================================================================================
🚀 COMO RODAR O LOCALAI ASSISTANT - FORMA RÁPIDA
================================================================================

PRÉ-REQUISITOS INSTALADOS:
✅ Python 3.11+
✅ Node.js 20+
✅ Git
✅ Ollama (com modelo dolphin-mistral baixado)

================================================================================

PASSO 1: Abra o PRIMEIRO CMD e execute os comandos (um por um, PRESSIONE ENTER após cada um):

cd %USERPROFILE%\Desktop\localai-assistant
[PRESSIONE ENTER]

cd backend
[PRESSIONE ENTER]

python -m venv venv
[PRESSIONE ENTER]

venv\Scripts\activate
[PRESSIONE ENTER]

pip install --upgrade pip setuptools wheel
[PRESSIONE ENTER]

pip install -r requirements.txt
[PRESSIONE ENTER - AGUARDE 3-5 MINUTOS]

python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
[PRESSIONE ENTER]

✅ DEIXE ABERTO!

================================================================================

PASSO 2: Abra um SEGUNDO CMD NOVO e execute os comandos (um por um, PRESSIONE ENTER após cada um):

cd %USERPROFILE%\Desktop\localai-assistant\frontend
[PRESSIONE ENTER]

npm install
[PRESSIONE ENTER - AGUARDE 2-3 MINUTOS]

npm run dev
[PRESSIONE ENTER]

✅ DEIXE ABERTO!

================================================================================

PASSO 3: Abra um TERCEIRO CMD NOVO e execute:

ollama serve
[PRESSIONE ENTER]

✅ DEIXE ABERTO!

================================================================================

PASSO 4: Abra seu navegador e acesse:

http://localhost:3000/

================================================================================

✅ PRONTO! O projeto está rodando!

Você deve ter 3 terminais CMD abertos:
  Terminal 1: Backend (porta 8000)
  Terminal 2: Frontend (porta 3000)
  Terminal 3: Ollama (porta 11434)
